# Урок 06. Массивы: несколько значений в одной переменной

**Время:** 45–75 минут (оценка)
**Уровень:** начинающий
**Пререквизиты:** пройдены [Урок 00](LESSON-00.md), [Урок 01](LESSON-01.md), [Урок 02](LESSON-02.md), [Урок 03](LESSON-03.md), [Урок 04](LESSON-04.md) и [Урок 05](LESSON-05.md). У вас есть работающая страница со счётчиком, сообщением «Цель достигнута!», кнопкой «Поменять оформление» и функцией `achievementMessage()`.
**Результат:** вы можете хранить несколько связанных значений в одной переменной, брать нужное по номеру, узнавать количество элементов и предсказывать, что изменится после добавления нового.

> **Главная идея урока.** До сих пор в переменной лежало **одно** значение. Сегодня мы научимся класть в переменную **несколько** значений сразу — в **массив**. Это первый шаг к трекеру задач: список дел, у которого есть порядок и длина.

## Шаг 1. Predict — сначала предсказываем (10 минут)

### Что мы собираемся сделать

Все задачи, которые нам понадобятся, — это просто **список названий**. Написать их по одному в отдельные переменные неудобно:

```javascript
const task1 = 'Прочитать главу';
const task2 = 'Сделать упражнение';
const task3 = 'Проверить результат';
```

Теперь их три, а завтра будет тридцать. Нужен **один** ящик, в котором лежат все названия по порядку. Такой ящик в JavaScript называется **массив**.

Вот так выглядит массив из трёх названий:

```javascript
const tasks = [
  'Прочитать главу',
  'Сделать упражнение',
  'Проверить результат'
];
```

Квадратные скобки `[ ]` — это **литерал массива**: запись, в которой мы перечисляем элементы через запятую.

### Запишите предсказания ДО запуска

Это главное упражнение урока. Ниже — тот же массив, который мы получим. **Прежде чем запускать код**, запишите в таблицу, что вернёт каждое выражение:

```javascript
const tasks = [
  'Прочитать главу',
  'Сделать упражнение',
  'Проверить результат'
];

tasks[0]
tasks[1]
tasks[2]
tasks.length
tasks[3]
```

| Выражение | Ваше предсказание |
|---|---|
| `tasks[0]` | |
| `tasks[1]` | |
| `tasks[2]` | |
| `tasks.length` | |
| `tasks[3]` | |

**Не переходите к следующему шагу, пока таблица не заполнена.**

> **Подсказка (только если совсем не получается).** Первый элемент массива — «Прочитать главу», второй — «Сделать упражнение», третий — «Проверить результат». Их **три**. Номер у первого элемента не `1`, а `0`. Поэтому у третьего элемента номер `2`. Последний элемент имеет номер на единицу меньше, чем их количество.

## Шаг 3. Investigate — разбираем, что произошло (15 минут)

### Элементы и их номера

Посмотрите на массив и пронумеруйте элементы **с нуля**:

```javascript
const tasks = [
  'Прочитать главу',      // tasks[0]
  'Сделать упражнение',   // tasks[1]
  'Проверить результат'   // tasks[2]
];
```

- **Элемент** — одно значение внутри массива. Здесь их три.
- **Индекс** — номер элемента. У первого он равен `0`, у второго — `1`, у третьего — `2`.

### Почему индексы начинаются с нуля

Это решение языка, а не ваш выбор и не ошибка. Нумерация «с нуля» означает, что **индекс — это не «сколько элементов перед этим», а «какой это по счёту элемент, считая с нуля»**. Первый элемент — нулевой, потому что перед ним ничего нет.

Отсюда простое правило, которое пригодится дальше:

> **Последний номер элемента = `length` − 1.**

Для нашего массива: `3 − 1 = 2` — это номер последнего элемента, `tasks[2]`. Верно.

### Почему `length` равна трём

`length` — это **свойство** массива: сколько в нём сейчас элементов. У нашего массива их три, поэтому `tasks.length` равна `3`.

`length` — не отдельная переменная и не функция. Это **свойство**: значение, которое лежит рядом с элементами и всегда показывает актуальное число элементов.

### Что будет, если прочитать элемент за пределами массива

А теперь главный вопрос: что покажет `tasks[3]`, когда элементов всего три?

```javascript
tasks[3] // undefined
```

**`undefined`** — это специальное значение JavaScript, означающее «значения нет». Никакой ошибки не возникнет: это **обычное чтение за пределами** для такого массива, а не исключение.

Почему так? У массива нет элемента с номером `3`, поэтому и значения нет — и `tasks[3]`, и `tasks[99]` вернут `undefined`. Ничего не сломается, но и пользы от такого чтения никакой.

> **Важно:** `undefined` означает «здесь ничего не лежит», а не «здесь ошибка». Ошибка — это когда код не может продолжить работу (например, вызвать `undefined` как функцию). Обычное чтение отсутствующего элемента — спокойная операция.

### Переменная и её содержимое — разные вещи

Вот это отличие стоит запомнить:

| Что | Как называется | Пример |
|---|---|---|
| `tasks` | **переменная** — «ящик» с именем | `const tasks = [...]` |
| `'Прочитать главу'`, `'Сделать упражнение'`, `'Проверить результат'` | **элементы** — вещи внутри ящика | `tasks[0]`, `tasks[1]`, `tasks[2]` |

Массив — **упорядоченная коллекция значений**. Порядок важен: `tasks[0]` — всегда первый, `tasks[1]` — всегда второй. Если элементы поменять местами, поменяются местами и то, что по этим индексам.

### `const` не значит «нельзя менять»

Вот это нужно понять до конца урока, потому что дальше будет легче.

Мы объявили массив так:

```javascript
const tasks = ['Прочитать главу', 'Сделать упражнение', 'Проверить результат'];
```

Ключевое слово `const` означает: **саму переменную нельзя переприсвоить**. Нельзя сделать `tasks = [...]` — это ошибка.

Но `const` **не означает**, что содержимое массива неизменно. Массив — это ящик, а `const` говорит только: «этот ящик всегда будет тем же ящиком». Что лежит **внутри** ящика — можно менять.

Поэтому `const` и массив — нормальное сочетание, и именно так принято писать:

```javascript
const tasks = ['Прочитать главу'];   // const — ок
tasks.push('Ещё одна');              // содержимое изменить — тоже ок
```

> **Кратко:** `const` защищает **имя** ящика, а не его содержимое.

## Шаг 4. Modify — добавляем четвёртую задачу (15 минут)

### Что мы собираемся сделать

Массив из трёх задач — это хорошо, но список должен расти. Для этого есть метод `push()`: он **добавляет один элемент в конец** массива.

### Запишите предсказания ДО запуска

```javascript
tasks.push('Повторить материал');
```

**Предскажите:**

1. Каким станет `tasks.length`? ___
2. Что вернёт `tasks[3]`? ___
3. Изменилась ли первая задача (`tasks[0]`)? ___

> **Подсказка (только если совсем не получается).** `push()` добавляет элемент **в конец**. Значит, новый элемент получит номер `3`, элементов станет четыре, а первые три останутся на своих местах.

### Выполните

Вставьте строку **в свой файл** рядом с объявлением массива:

```javascript
const tasks = [
  'Прочитать главу',
  'Сделать упражнение',
  'Проверить результат'
];

tasks.push('Повторить материал');
```

Теперь проверьте в консоли:

```javascript
tasks.length   // 4
tasks[3]       // 'Повторить материал'
tasks[0]       // 'Прочитать главу' — не изменилась
```

| Что | Ваше предсказание | Что показала консоль | Совпало? |
|---|---|---|---|
| Новое `tasks.length` | | | ☐ |
| Значение `tasks[3]` | | | ☐ |
| Первая задача `tasks[0]` | | | ☐ |

### Почему число на странице может остаться старым

Откройте страницу и посмотрите на блок «Ближайшая задача».

**Если `tasks.push(...)` находится в файле, а страницу вы обновили (`F5`)** — число задач станет `4`. Всё правильно.

**Если вы вставили `push()` только в консоли** — число на странице останется `3`. И это **не ошибка**. Вот почему:

- Консоль выполняет код **прямо сейчас**, в том состоянии, в котором сейчас страница.
- Страница же получила эти данные **при загрузке страницы**: `startCounter()` выполнился один раз, записал `tasks.length` в `#task-count` и всё.
- Чтобы страница взяла новое значение, её нужно **перезагрузить** (`F5`) — тогда скрипт выполнится заново, уже с новым массивом.

**Поэтому проверяйте так:**

1. Вставьте `push()` **в файл**, сохраните, обновите страницу (`F5`).
2. В блоке «Ближайшая задача» должно быть: всего задач — `4`.
3. Первая задача осталась прежней — `Прочитать главу`.

> **Проверка на «всё живое».** Нажмите кнопку счётчика: он должен работать как раньше, сообщение должно меняться, кнопка оформления — переключать тему. Новая часть урока не должна была ничего сломать.

> **Как вернуть всё как было?** Удалите строку `tasks.push('Повторить материал');` из файла, сохраните и обновите страницу. Число задач снова станет `3`. Это хорошая проверка: значит, число на странице действительно берётся из массива, а не написано руками.

## Шаг 5. Make — свои три задачи (необязательно, 10–15 минут)

> **Этот шаг необязательный.** Он не входит в критерий завершения урока и не является условием для Урока 07. Если времени нет — пропустите его и переходите к проверке.

Придумайте **три** своих задачи и положите их в массив. Только строки — без объектов, без циклов.

```javascript

  'Первая моя задача',
  'Вторая моя задача',
```

- Что вернёт `myTasks[0]`? ___

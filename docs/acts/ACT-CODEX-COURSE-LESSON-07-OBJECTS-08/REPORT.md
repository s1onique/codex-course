## 4. Урок 07 — концепции и упражнения

Создан `LESSON-07.md` (461 строка), заголовок: **«Урок 07. Объекты: несколько свойств одной задачи»**, оценка времени 45–75 минут, пререквизиты — Уроки 00–06.

**Главная модель:** объект группирует несколько именованных свойств, описывающих одну сущность. Различие с Уроком 06 проведено явно: массив — упорядоченная коллекция значений, доступ по номеру; объект — связанные свойства одной сущности, доступ по имени. Урок прямо запрещает формулировку «объект — это неупорядоченный массив».

**Введённые понятия:** литерал объекта `{}`; имя свойства и значение; разделитель `:`; точечная запись для чтения; точечная запись для изменения; строковое свойство (`title`) и логическое (`done`); различие `const`-связывания и мутации объекта.

**Не введено:** конструкторы и классы, прототипы и наследование, геттеры и сеттеры, методы и `this`, деструктуризация и spread, вложенные объекты, массивы объектов, итерация по объекту, `Object.keys()`/`values()`/`entries()`, JSON, TypeScript, асинхронность, новая оснастка.

**Канонический пример** (в уроке приведён дословно):

```javascript
const exampleTask = {
  title: 'Составить план',
  done: false
};
```

**Видимый результат:** блок «Пример задачи» с новыми уникальными ID `#example-task-title` и `#example-task-status`; значение состояния получается через уже знакомый из Урока 04 `if`/`else`; показ выполняется существующим механизмом инициализации из Урока 05/06 (`startCounter()`), **без нового обработчика и без новой кнопки**. Блок «Ближайшая задача» не перезаписывается.

**Граница интеграции.** Массив `tasks` из Урока 06 остаётся тремя строками и **не** заменяется объектами. В уроке есть отдельная таблица сравнения `tasks` и `exampleTask` и явное предупреждение, что `exampleTask` не входит в `tasks`, не связан с ним и никак не синхронизирован; связывание отнесено к следующему уроку.

**PRIMM.** Predict (первое содержательное предсказание — таблица из 4 выражений, до запуска) → Run → Investigate → Modify → Make (необязательный).

**Modify** — смена состояния в исходнике с восстановлением: `done: false` → `done: true` → `false`, с проверкой `Выполнена` / `Не выполнена` и фиксацией того, что блок «Ближайшая задача» не меняется.

**Make (необязательный)** — свой объект `myTask`; прямо сказано не добавлять его в `tasks` и не выводить в новый раздел; не является условием для Урока 08.

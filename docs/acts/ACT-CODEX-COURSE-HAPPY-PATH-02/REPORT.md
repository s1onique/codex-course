> 6 фаз, ориентировочно 40–60 занятий по 45–75 минут. При двух занятиях в неделю это **20–30 недель (примерно 5–7 месяцев)** без учёта пропусков. С учётом holiday-пауз, повторения пройденного и времени на самостоятельную работу между занятиями реалистичный горизонт — **8–12 месяцев**.

# Вайбкодинг с Codex: программа курса

**Версия:** 0.1  
**Дата:** 2026-11-11  
**Целевая аудитория:** начинающий пользователь, который знаком с Markdown, имеет GitHub-репозиторий, подписку ChatGPT и установленный Codex. Знание языков программирования не требуется.  
**Продолжительность:** 14 занятий по 45–75 минут, примерно 7 недель при двух занятиях в неделю.  
**Метод:** каждый урок заканчивается работающим результатом, самостоятельной проверкой и фиксацией того, что сделано и что не проверено.

## Цель

После прохождения курса участница сможет самостоятельно сформулировать небольшую задачу, поручить её Codex, понимать границы доступа агента, проверить результат, сохранить изменения в Git/GitHub, опубликовать простое приложение и безопасно подключить внешний сервис.

## Программа

| № | Тема | Результат практики | Что проверяем |
|---|---|---|---|
| 0 | Установка Git for Windows и подключение репозитория | `git` доступен в PowerShell, свой репозиторий открыт в Codex | Проверены `git --version`, `git status`, `git remote -v` |
| 1 | Знакомство с Codex и первый проект | Самостоятельная интерактивная HTML-страница | Открывается локально, кнопка работает, чужие файлы не затронуты |
| 2 | Промптинг: цель, контекст, ограничения, критерии | Управляемое улучшение собственной страницы | Изменения соответствуют трём наблюдаемым требованиям |
| 3 | Git и GitHub: коммиты, ветки, PR и возврат | Безопасно опубликованное изменение в репозитории | Можно показать commit, diff и историю |
| 4 | Основы HTML, CSS и JavaScript | Объяснение и изменение трёх частей страницы | Понятно, что отвечает за текст, стиль и поведение |
| 5 | От страницы к приложению | Список задач с добавлением, отметками и сохранением | Данные не теряются после перезагрузки; пограничные случаи |
| 6 | Модели, агенты и контекст проекта | Короткий `AGENTS.md` для своего репозитория | Агент следует проектным договорённостям |
| 7 | Ошибки, отладка, тестирование | Исправление намеренно сломанного поведения | Ошибка воспроизведена до правки и устранена после |
| 8 | Публикация: GitHub Pages | Доступная по ссылке статическая страница | Ссылка открывается в приватном окне; нет секретов в коде |
| 9 | HTTP, API и JSON | Страница, получающая публичные данные | Есть обработка ошибок и пустых ответов |
| 10 | Доступы, API-ключи, OAuth | Макет интеграции на тестовых данных | Секреты не попадают в Git или клиентский JavaScript |
| 11 | Webhooks и workflows | Простой событийный сценарий в n8n/аналоге | Получено тестовое событие; повтор не ломает результат |
| 12 | MCP, skills и плагины | Узкий повторно используемый сценарий | Известны права, входы, выходы и ограничения |
| 13 | Файлы и документы | Разбор набора документов или отчёт | Проверены исходники и итоговые файлы |
| 14 | Выпускной проект | Самостоятельный полезный инструмент | Работает, проверен, задокументирован и сохранён |

## Схема одного занятия

- 10 минут — короткий разбор концепции и демонстрация.
- 30–45 минут — самостоятельная практика в Codex.
- 10–15 минут — проверка и разбор ошибок.
- 5 минут — фиксация результата и одного нового навыка.

## Принципы

1. **Сразу практикуем.** Не нужно изучать модели и токены до первого работающего проекта.
2. **Один шаг — один проверяемый результат.** Начинаем с небольших ограниченных задач.
3. **Факты отделяем от заявлений агента.** Если тест не запускался, он не считается пройденным.
4. **Сначала без внешних доступов.** На начальных уроках не нужны API-ключи, MCP, хостинг или платные сервисы.
5. **Защищаем существующую работу.** Не удаляем файлы, не перезаписываем чужие изменения, не используем команды без понимания последствий.
6. **Codex — исполнитель, человек — автор решения.** Качество определяется поведением готового результата, а не красотой ответа агента.

## Что НЕ требуется в начале курса

- Покупать API-кредиты или выпускать API-ключ OpenAI для входа в Codex через ChatGPT.
- Устанавливать веб-фреймворки и менеджеры пакетов.
- Подключать GitHub MCP или выдавать персональный токен GitHub только ради локального проекта.
- Изучать терминал глубже нескольких базовых команд.
